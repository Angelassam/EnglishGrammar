# [2-07] so ~ that — 중2

## 객관식 (알맞은 말 고르기) (6)

**1.** 두 문장이 같은 뜻이 되도록 빈칸에 알맞은 말을 고르세요. / The box was too heavy for me to carry by myself. / = The box was so heavy that I ____ carry it by myself.  
① couldn't  
② can't  
③ could  
④ can  
⑤ won't  
> **정답** ① couldn't  
> **해설** too ~ to는 부정의 뜻이라 so ~ that 뒤에 can't/couldn't가 오고, 시제가 과거(was)라서 couldn't를 써요. could는 긍정이라 뜻이 반대가 돼요.  
> 근거: 5. too ~ to / enough to ↔ so ~ that 전환

**2.** 우리말과 같은 뜻이 되도록 빈칸에 알맞은 말을 고르세요. / 지난여름에 아빠는 내가 호텔을 쉽게 찾을 수 있도록 나에게 지도를 그려 주셨다. / Last summer, my dad drew a map for me so that I ____ find the hotel easily.  
① could  
② can  
③ couldn't  
④ has to  
⑤ will  
> **정답** ① could  
> **해설** 목적을 나타내는 so that + 주어 + can/could에서 주절이 과거(drew, last summer)라서 could로 시제를 맞춰요. can, will은 시제가 맞지 않아요.  
> 근거: 2. so that + 주어 + can/will — 목적

**3.** 빈칸에 들어갈 말로 어법상 옳은 것을 고르세요. / It was ____ that nobody wanted to go outside.  
(너무 더운 날이어서 아무도 밖에 나가고 싶어 하지 않았다.)  
① such a hot day  
② so a hot day  
③ a such hot day  
④ such hot a day  
⑤ so hot day  
> **정답** ① such a hot day  
> **해설** 명사를 강조할 때는 such + a(n) + 형용사 + 명사 + that 순서예요. so a hot day처럼 so 뒤에 a가 바로 오는 어순은 틀려요.  
> 근거: 4. such + a(n) + 형용사 + 명사 + that

**4.** 밑줄 친 부분과 바꿔 쓸 수 있는 것을 고르세요. / She took notes in class **so that** she could review them later.  
(그녀는 나중에 복습할 수 있도록 수업 중에 필기를 했다.)  
① in order that  
② in order to  
③ so as to  
④ too  
⑤ such that  
> **정답** ① in order that  
> **해설** 목적의 so that + 주어 + 동사는 in order that + 주어 + 동사로 바꿔 쓸 수 있어요. in order to, so as to 뒤에는 주어 없이 동사원형이 와서 여기서는 쓸 수 없어요.  
> 근거: 2. so that + 주어 + can/will — 목적

**5.** 두 문장이 같은 뜻이 되도록 빈칸에 알맞은 말을 고르세요. / She is so smart that she can solve the problem alone. / = She is smart ____ the problem alone.  
① enough to solve  
② too to solve  
③ enough solving  
④ to solve enough  
⑤ enough solve  
> **정답** ① enough to solve  
> **해설** so ~ that 주어 can(긍정)은 형용사 + enough to로 바꿔요. enough는 형용사 뒤에 오고 그 뒤에 to + 동사원형이 와요.  
> 근거: 5. too ~ to / enough to ↔ so ~ that 전환

**6.** 다음 중 so (that)의 쓰임(목적/결과)이 나머지 넷과 **다른** 것을 고르세요.  
① He was so tired that he could not finish his homework.  
② I turned off the TV so that my brother could sleep.  
③ She wrote the number down so that she wouldn't forget it.  
④ We left early so that we could get good seats.  
⑤ He speaks loudly so that everyone can hear him.  
> **정답** ① He was so tired that he could not finish his homework.  
> **해설** so 바로 뒤에 형용사(tired)가 오면 '너무 ~해서 …하다'는 결과예요. 나머지는 so that 뒤에 바로 주어 + can/will이 와서 '~하기 위해서'라는 목적이에요.  
> 근거: 3. 구별 팁

## 객관식 (어법상 틀린 것 고르기) (3)

**1.** 다음 중 어법상 틀린 문장을 고르세요.  
① During the test yesterday, the teacher opened the window so that we can get some fresh air.  
② The movie was so sad that everyone in the theater cried.  
③ It was such a boring lecture that half of the students fell asleep.  
④ He explained the rules twice so that the new members could understand them.  
⑤ The river is so wide that you cannot see the other side.  
> **정답** ① During the test yesterday, the teacher opened the window so that we can get some fresh air.  
> **해설** 주절이 과거(opened, yesterday)이면 so that 뒤의 can도 could로 시제를 맞춰야 해요. → During the test yesterday, the teacher opened the window so that we could get some fresh air.  
> 근거: 2. so that + 주어 + can/will — 목적

**2.** 다음 중 어법상 틀린 문장을 고르세요.  
① He is so a kind person that everyone in the office likes him.  
② The soup was so salty that nobody at the table could finish it.  
③ I took a taxi so that I could get to the airport on time.  
④ It was such a long movie that we took a break in the middle.  
⑤ The question was so easy that even the little kids could answer it.  
> **정답** ① He is so a kind person that everyone in the office likes him.  
> **해설** a + 형용사 + 명사 앞에는 so가 아니라 such를 써요. → He is such a kind person that everyone in the office likes him. (so kind a person도 가능해요.)  
> 근거: 4. such + a(n) + 형용사 + 명사 + that

**3.** 다음 중 어법상 틀린 문장을 고르세요.  
① The problem was so difficult that nobody in the class could solve.  
② The water was too cold for the children to swim in.  
③ The bag was so light that I could carry it with one hand.  
④ This tea is too hot to drink right now.  
⑤ He is tall enough to touch the ceiling without a chair.  
> **정답** ① The problem was so difficult that nobody in the class could solve.  
> **해설** too ~ to를 so ~ that으로 바꿀 때 that절에는 목적어 it을 빠뜨리면 안 돼요. → The problem was so difficult that nobody in the class could solve it.  
> 근거: 5. too ~ to / enough to ↔ so ~ that 전환

## 빈칸 채우기 (3)

**1.** 두 문장이 같은 뜻이 되도록 빈칸에 알맞은 말을 쓰세요. (can의 부정형을 시제에 맞게) / The test was too hard for me to finish in time. / = The test was so hard that I ____ finish it in time.  
(그 시험은 너무 어려워서 나는 제시간에 그것을 끝낼 수 없었다.)  
> **정답** couldn't / could not  
> **해설** too ~ to는 부정의 뜻이고 시제가 과거라서 couldn't를 써요. 목적어 it도 함께 들어가요.  
> 근거: 5. too ~ to / enough to ↔ so ~ that 전환

**2.** 괄호 안의 말을 알맞은 형태로 바꿔 빈칸에 쓰세요. / Grandma spoke slowly and clearly so that we ____ understand every word she said. (can)  
(할머니는 우리가 그녀가 말하는 모든 단어를 이해할 수 있도록 천천히 또렷하게 말씀하셨다.)  
> **정답** could  
> **해설** 목적의 so that 뒤에는 주어 + can/could가 오는데, 주절이 과거(spoke)라서 could로 맞춰요.  
> 근거: 2. so that + 주어 + can/will — 목적

**3.** 두 문장이 같은 뜻이 되도록 빈칸에 알맞은 말을 쓰세요. (so, large, that을 이용, 세 단어) / The room is large enough to hold fifty people. / = The room is ____ it can hold fifty people.  
(그 방은 50명을 수용할 만큼 충분히 크다.)  
> **정답** so large that  
> **해설** 형용사 + enough to는 so + 형용사 + that 주어 can(긍정)으로 바꿔요. 그래서 so large that이에요.  
> 근거: 5. too ~ to / enough to ↔ so ~ that 전환

## 틀린 부분 고쳐 쓰기 (3)

**1.** I got up at five so that I can see the sunrise from the top of the mountain.  
(나는 산 정상에서 일출을 보기 위해서 5시에 일어났다.)  
> **정답** can → could  
> **해설** 목적의 so that절은 주절 시제에 맞춰요. 주절이 과거(got up)라서 can → could로 고쳐요.  
> 근거: 2. so that + 주어 + can/will — 목적

**2.** She told such funny a story that we couldn't stop laughing for a while.  
(그녀가 너무 재미있는 이야기를 해서 우리는 한동안 웃음을 멈출 수 없었다.)  
> **정답** such funny a story → such a funny story / so funny a story  
> **해설** such 뒤에는 a + 형용사 + 명사 순서예요. such funny a story → such a funny story (so를 쓰면 so funny a story)  
> 근거: 4. such + a(n) + 형용사 + 명사 + that

**3.** The music was too loud that we couldn't hear each other at the party.  
(음악이 너무 시끄러워서 우리는 파티에서 서로의 말을 들을 수 없었다.)  
> **정답** too loud that → so loud that  
> **해설** 뒤에 that + 주어 + 동사가 오면 too가 아니라 so + 형용사 + that으로 써요. too는 to부정사와 짝을 이뤄요. too loud that → so loud that  
> 근거: 1. so + 형용사/부사 + that — 결과

## 배열·영작 (3)

**1.** 그 텐트는 너무 커서 그 어린 소년은 그것을 혼자 설치할 수 없었다.  
[ so / that / the little boy / couldn't / set it up / alone / The tent was / big ]  
> **정답** The tent was so big that the little boy couldn't set it up alone.  
> **해설** so + 형용사(big) + that + 주어 + 동사 순서로 결과를 나타내요. 부정의 결과라서 couldn't를 써요.  
> 근거: 1. so + 형용사/부사 + that — 결과

**2.** 그는 첫 기차를 탈 수 있도록 알람을 6시에 맞췄다.  
[ he / set / the alarm / for six / so that / can / catch / the first train ] — 주어진 말을 이용하고, 필요하면 단어를 더하거나 형태를 바꾸세요.  
> **정답** He set the alarm for six so that he could catch the first train. / So that he could catch the first train, he set the alarm for six.  
> **해설** 목적은 so that + 주어 + could로 쓰고, 주절이 과거(set)라서 can을 could로 바꿔요. so that 뒤에 주어 he를 다시 써야 해요.  
> 근거: 2. so that + 주어 + can/will — 목적

**3.** 그 가방은 너무 비싸서 나는 그것을 살 수 없었다.  
[ the bag / be / so / expensive / that / I / can / buy / it ] — 주어진 말을 이용하고, 필요하면 단어를 더하거나 형태를 바꾸세요.  
> **정답** The bag was so expensive that I couldn't buy it. / The bag was so expensive that I could not buy it.  
> **해설** '너무 ~해서 …할 수 없었다'는 so + 형용사 + that + 주어 + couldn't로 써요. 과거라서 be → was, can → couldn't로 바꿔요.  
> 근거: 5. too ~ to / enough to ↔ so ~ that 전환
