## 객관식 (알맞은 말 고르기) (13)

**1.** 우리말과 같은 뜻이 되도록 빈칸에 알맞은 말을 고르세요. / 수프가 너무 뜨거워서 나는 그것을 먹을 수 없었다. / The soup was ____ hot that I couldn't eat it.  
① so  
② such  
③ too  
④ very  
⑤ enough  
> **정답** ① so  
> **해설** '너무 ~해서 …하다'는 so + 형용사 + that으로 써요. such는 명사 앞에, too와 very는 that절과 짝을 이루지 않아요.  
> 근거: 1. so + 형용사/부사 + that — 결과

**2.** 우리말과 같은 뜻이 되도록 빈칸에 알맞은 말을 고르세요. / 그녀는 시험에 합격하기 위해서 열심히 공부했다. / She studied hard ____ she could pass the exam.  
① so that  
② in order to  
③ so as to  
④ because of  
⑤ such  
> **정답** ① so that  
> **해설** '~하기 위해서'라는 목적은 so that + 주어 + can/could로 써요. in order to와 so as to 뒤에는 주어 없이 동사원형이 와요.  
> 근거: 2. so that + 주어 + can/will — 목적

**3.** 빈칸에 알맞은 말을 고르세요. / He ran so fast ____ he won the race.  
(그는 너무 빨리 달려서 경주에서 이겼다.)  
① that  
② what  
③ which  
④ to  
⑤ if  
> **정답** ① that  
> **해설** so + 부사(fast) 뒤에 that + 주어 + 동사가 와서 결과를 나타내요.  
> 근거: 1. so + 형용사/부사 + that — 결과

**4.** 우리말과 같은 뜻이 되도록 빈칸에 알맞은 말을 고르세요. / 그것은 너무 재미있는 책이어서 나는 두 번 읽었다. / It was ____ an interesting book that I read it twice.  
① such  
② so  
③ very  
④ too  
⑤ enough  
> **정답** ① such  
> **해설** 뒤에 a(n) + 형용사 + 명사가 오면 so가 아니라 such를 써요. so an interesting book은 틀린 어순이에요.  
> 근거: 4. such + a(n) + 형용사 + 명사 + that

**5.** 두 문장이 같은 뜻이 되도록 빈칸에 알맞은 말을 고르세요. / The coffee was too hot to drink. / = The coffee was so hot that I ____ drink it.  
① couldn't  
② could  
③ can  
④ wasn't  
⑤ am not  
> **정답** ① couldn't  
> **해설** too ~ to는 부정의 뜻이라 so ~ that 뒤에 can't/couldn't가 와요. 시제가 과거(was)라서 couldn't를 써요.  
> 근거: 5. too ~ to / enough to ↔ so ~ that 전환

**6.** 두 문장이 같은 뜻이 되도록 빈칸에 알맞은 말을 고르세요. / He is tall enough to reach the shelf. / = He is so tall that he ____ reach the shelf.  
① can  
② can't  
③ couldn't  
④ doesn't  
⑤ isn't  
> **정답** ① can  
> **해설** enough to는 긍정의 뜻이라 so ~ that 뒤에 can이 와요. 시제가 현재(is)라서 can을 써요.  
> 근거: 5. too ~ to / enough to ↔ so ~ that 전환

**7.** 밑줄 친 부분의 뜻으로 알맞은 것을 고르세요. / I woke up early **so that** I could catch the bus.  
① ~하기 위해서  
② 너무 ~해서  
③ 그래서  
④ ~하는 동안  
⑤ ~이기 때문에  
> **정답** ① ~하기 위해서  
> **해설** so 바로 뒤에 that + 주어 + could가 오면 '~하기 위해서'라는 목적의 뜻이에요.  
> 근거: 3. 구별 팁

**8.** 다음 중 '너무 ~해서 …하다'(결과)의 뜻을 나타내는 문장을 고르세요.

> 근거: 3. 구별 팁

**9.** 다음 중 어법상 옳은 문장을 고르세요.

> 근거: 4. such + a(n) + 형용사 + 명사 + that

**10.** 대화의 빈칸에 알맞은 말을 고르세요. / A: Why did you save money? / B: I saved money ____ I could buy a car.

**11.** 밑줄 친 부분과 바꿔 쓸 수 있는 것을 고르세요. / I got up early **so that** I could get there on time.

**12.** 두 문장이 같은 뜻이 되도록 빈칸에 알맞은 말을 고르세요. / He was so tired that he couldn't walk. / = He was ____ tired to walk.

**13.** 두 문장이 같은 뜻이 되도록 빈칸에 알맞은 말을 고르세요. / This bag is so light that I can carry it. / = This bag is light ____ to carry.

## 틀린 부분 고쳐 쓰기 (7)

**1.** It was so an interesting book that I read it twice.  
(그것은 너무 재미있는 책이어서 나는 두 번 읽었다.)  
> **정답** so an → such an  
> **해설** a(n) + 형용사 + 명사 앞에는 such를 써요. so an → such an  
> 근거: 4. such + a(n) + 형용사 + 명사 + that

**2.** The soup was such hot that I couldn't eat it.  
(수프가 너무 뜨거워서 나는 그것을 먹을 수 없었다.)  
> **정답** such → so  
> **해설** 형용사(hot) 바로 앞에는 such가 아니라 so를 써요. such → so  
> 근거: 1. so + 형용사/부사 + that — 결과

**3.** He is so tall that he can't reach the shelf.  
(그는 키가 충분히 커서 선반에 닿을 수 있다.)  
> **정답** can't → can  
> **해설** '닿을 수 있다'는 긍정의 결과(enough to)라서 can을 써요. can't → can  
> 근거: 5. too ~ to / enough to ↔ so ~ that 전환

**4.** I woke up early yesterday so that I can catch the bus.  
(나는 어제 버스를 타기 위해서 일찍 일어났다.)  
> **정답** can → could  
> **해설** 앞 문장이 과거(woke up)라서 so that 뒤에도 과거형 could를 써요. can → could  
> 근거: 2. so that + 주어 + can/will — 목적

**5.** She is so a kind girl that everyone likes her.  
(그녀는 너무 친절한 소녀라서 모두가 그녀를 좋아한다.)  
> **정답** so a kind girl → such a kind girl / so kind a girl  
> **해설** 명사를 강조할 때는 such + a + 형용사 + 명사 어순이에요. so를 쓰려면 so kind a girl로 써요.  
> 근거: 4. such + a(n) + 형용사 + 명사 + that

**6.** He saved money such that he could buy a car.  
(그는 차를 사기 위해서 돈을 모았다.)  
> **정답** such that → so that  
> **해설** '~하기 위해서'라는 목적은 so that + 주어 + could로 써요. such that → so that  
> 근거: 2. so that + 주어 + can/will — 목적

**7.** The coffee was too hot that I couldn't drink it.  
(커피가 너무 뜨거워서 나는 그것을 마실 수 없었다.)  
> **정답** too → so  
> **해설** that절과 짝을 이루는 것은 so예요. too는 to부정사와 짝을 이뤄요(too hot to drink). too → so  
> 근거: 5. too ~ to / enough to ↔ so ~ that 전환

## 배열·영작 (6)

**1.** 그 방은 너무 어두워서 나는 아무것도 볼 수 없었다.

> **해설** 주어 + 동사 + so + 형용사 + that + 주어 + 동사 순서예요.  
> 근거: 1. so + 형용사/부사 + that — 결과

**2.** 우리는 그 영화를 보기 위해서 일찍 집에 왔다.

> **해설** 목적은 so that + 주어 + could + 동사원형 순서로 써요.  
> 근거: 2. so that + 주어 + can/will — 목적

> **해설** such + a + 형용사 + 명사 + that + 주어 + 동사 순서예요.  
> 근거: 4. such + a(n) + 형용사 + 명사 + that

> **해설** so that 뒤에 주어 + could + 동사원형이 와서 목적을 나타내요.  
> 근거: 2. so that + 주어 + can/will — 목적
