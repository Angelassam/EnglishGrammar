# [1-09] There is / are — 중1

근거 문서: 09_There_is_are.md · 총 18문제

## 객관식 (알맞은 말 고르기) (6)

**1.** 우리말과 같은 뜻이 되도록 빈칸에 알맞은 말을 고르세요. / 어젯밤에 지붕 위에 눈이 많이 있었다. / There ____ a lot of snow on the roof last night.  
① was  
② were  
③ is  
④ are  
⑤ had  
> **정답** ① was  
> **해설** snow는 셀 수 없는 명사라 양이 많아도 단수 취급해서 is/was를 쓰고, last night이 있으니 과거형 was예요. There 뒤에는 be동사만 써요.  
> 근거: 4. 셀 수 없는 명사는 is!

**2.** 대화의 빈칸에 알맞은 말을 고르세요. / A: ____ any good restaurants near the new shopping mall? / B: Yes, there are. There's a famous pizza place next to it.  
① Are there  
② Is there  
③ There are  
④ Do there  
⑤ Are they  
> **정답** ① Are there  
> **해설** There is/are의 의문문은 be동사를 There 앞으로 보내 Is/Are there ~?로 써요. restaurants가 복수라 Are there이고, 대답 there are와도 맞아요.  
> 근거: 3. 의문문 — Is / Are there ~?

**3.** 빈칸에 공통으로 알맞은 말을 고르세요. / There ____ a lot of information on this website about Korean history. / There ____ an old clock on the wall of my grandfather's room.  
① is  
② are  
③ were  
④ have  
⑤ has  
> **정답** ① is  
> **해설** information은 셀 수 없는 명사라 a lot of가 붙어도 is를 쓰고, an old clock은 단수라 is를 써요. There 뒤에 have/has는 쓰지 않아요.  
> 근거: 4. 셀 수 없는 명사는 is!

**4.** 다음 문장을 부정문으로 바르게 바꾼 것을 고르세요. / There were some children in the playground this morning.  
① There weren't any children in the playground this morning.  
② There weren't some children in the playground this morning.  
③ There didn't be any children in the playground this morning.  
④ There wasn't any children in the playground this morning.  
⑤ There not were any children in the playground this morning.  
> **정답** ① There weren't any children in the playground this morning.  
> **해설** 부정문은 be동사 뒤에 not을 붙이고, some 대신 any를 써요. children이 복수라 weren't이고, didn't는 쓰지 않아요.  
> 근거: 2. 부정문 — There is/are + not (+ any)

**5.** 다음 중 어법상 옳은 문장을 고르세요.  
① There is some money in my coat pocket, so I can buy lunch.  
② There have many beautiful parks in this city.  
③ Was there many students in the gym this morning?  
④ There isn't some milk in the fridge, so let's buy some.  
⑤ There are a new student in our class from Japan.  
> **정답** ① There is some money in my coat pocket, so I can buy lunch.  
> **해설** money는 셀 수 없는 명사라 There is가 맞아요. There have → There are, Was there many students → Were there many students, isn't some → isn't any, There are a new student → There is a new student로 고쳐야 해요.  
> 근거: 자주 하는 실수

**6.** 대화의 빈칸에 알맞은 말을 고르세요. / A: Was there a post office near your old house? / B: ____ I had to walk for thirty minutes to send a letter.  
① No, there wasn't.  
② No, there weren't.  
③ No, it wasn't.  
④ No, there isn't.  
⑤ No, there didn't.  
> **정답** ① No, there wasn't.  
> **해설** Was there ~?로 물으면 Yes, there was. / No, there wasn't.로 대답해요. 단수 a post office라 wasn't이고, 과거로 물었으니 isn't는 쓸 수 없어요.  
> 근거: 3. 의문문 — Is / Are there ~?

## 객관식 (어법상 틀린 것 고르기) (3)

**1.** 다음 중 어법상 틀린 문장을 고르세요.  
① There was many cars on the road because of the heavy rain.  
② There is a big park between the school and the library.  
③ There weren't any empty seats on the bus this morning.  
④ Is there a swimming pool in your new apartment building?  
⑤ There is a lot of sugar in this orange juice, so don't drink too much.  
> **정답** ① There was many cars on the road because of the heavy rain.  
> **해설** 뒤에 오는 명사 many cars가 복수라서 과거형도 were를 써요. → There were many cars on the road because of the heavy rain.  
> 근거: 1. 과거형 — There was / There were

**2.** 다음 중 어법상 틀린 문장을 고르세요.  
① There are some water in the bottle, so you can drink it.  
② There are three new students in our class this year.  
③ Were there many people at the museum last weekend?  
④ There wasn't any food in the fridge, so we ordered pizza.  
⑤ There is an old church at the end of this street.  
> **정답** ① There are some water in the bottle, so you can drink it.  
> **해설** water는 셀 수 없는 명사라서 some이 붙어도 is를 써요. → There is some water in the bottle, so you can drink it.  
> 근거: 4. 셀 수 없는 명사는 is!

**3.** 다음 중 어법상 틀린 문장을 고르세요.  
① There is some eggs in the basket, but there isn't any milk.  
② There aren't any buses to the airport after midnight.  
③ Is there any homework for tomorrow's math class?  
④ There was a small cafe here, but now there is a bank.  
⑤ There are twenty-five students in Minho's class.  
> **정답** ① There is some eggs in the basket, but there isn't any milk.  
> **해설** be동사는 뒤에 오는 진짜 주어에 맞춰요. some eggs는 복수라 are를 써야 해요. → There are some eggs in the basket, but there isn't any milk.  
> 근거: 자주 하는 실수

## 빈칸 채우기 (3)

**1.** 다음 문장을 의문문으로 바꿀 때 빈칸에 알맞은 말을 쓰세요. (세 단어) / There was some soup in the pot on the stove. / → ____ soup in the pot on the stove?  
(가스레인지 위의 냄비에 수프가 조금 있었니?)  
> **정답** Was there any  
> **해설** 의문문은 be동사를 There 앞으로 보내 Was there ~?로 쓰고, 의문문에서는 some 대신 any를 써요.  
> 근거: 3. 의문문 — Is / Are there ~?

**2.** 괄호 안의 말을 알맞은 현재형으로 바꿔 빈칸에 쓰세요. / There ____ not much time before the last train leaves, so hurry up. (be)  
(마지막 기차가 떠나기 전까지 시간이 많지 않으니 서둘러.)  
> **정답** is  
> **해설** time은 셀 수 없는 명사라서 There is를 쓰고, 부정은 is 뒤에 not을 붙여요.  
> 근거: 4. 셀 수 없는 명사는 is!

**3.** 우리말과 같은 뜻이 되도록 빈칸에 알맞은 말을 쓰세요. (세 단어) / 지난주에는 이 근처에 꽃집이 하나도 없었다. / ____ flower shops near here last week.  
(지난주에는 이 근처에 꽃집이 하나도 없었다.)  
> **정답** There weren't any / There were not any  
> **해설** flower shops가 복수이고 last week이 있으니 과거형 were를 쓰고, 부정문은 not (+ any)를 붙여 There weren't any ~로 써요.  
> 근거: 2. 부정문 — There is/are + not (+ any)

## 틀린 부분 고쳐 쓰기 (3)

**1.** There is a lot of interesting books in the school library.  
(학교 도서관에는 흥미로운 책이 많이 있다.)  
> **정답** is → are  
> **해설** be동사는 There 뒤에 오는 진짜 주어에 맞춰요. a lot of 뒤의 books가 복수라서 are를 써요. is → are  
> 근거: 자주 하는 실수

**2.** Were there a big tree in front of your house ten years ago?  
(10년 전에 너희 집 앞에 큰 나무가 한 그루 있었니?)  
> **정답** Were → Was  
> **해설** 의문문에서도 be동사는 뒤의 명사에 맞춰요. a big tree는 단수라서 과거형 Was를 써요. Were → Was  
> 근거: 3. 의문문 — Is / Are there ~?

**3.** There isn't some information about the festival on the website.  
(웹사이트에 그 축제에 관한 정보가 하나도 없다.)  
> **정답** some → any  
> **해설** 부정문에서는 some 대신 any를 써요. information은 셀 수 없는 명사라 isn't는 맞아요. some → any  
> 근거: 2. 부정문 — There is/are + not (+ any)

## 배열·영작 (3)

**1.** 지난 토요일 밤에 그 콘서트에 사람들이 많이 있었니?  
[ there / at the concert / Were / night / many people / last / Saturday ]  
> **정답** Were there many people at the concert last Saturday night?  
> **해설** 과거 의문문은 Were there + 복수명사 ~? 순서로 쓰고, 장소와 때를 뒤에 이어요.  
> 근거: 1. 과거형 — There was / There were

**2.** 이 병에는 주스가 많이 있지만, 유리잔에는 하나도 없다.  
[ there / be / a lot of / juice / in this bottle / but / not / any / in the glass ] — 주어진 말을 이용하고, 필요하면 단어를 더하거나 형태를 바꾸세요.  
> **정답** There is a lot of juice in this bottle, but there isn't any in the glass. / There is a lot of juice in this bottle, but there is not any in the glass. / There's a lot of juice in this bottle, but there isn't any in the glass. / There's a lot of juice in this bottle, but there is not any in the glass.  
> **해설** juice는 셀 수 없는 명사라 a lot of가 붙어도 There is로 쓰고, 부정은 there isn't any로 써요. 두 문장은 but으로 이어요.  
> 근거: 4. 셀 수 없는 명사는 is!

**3.** 우리 교실에는 컴퓨터가 한 대도 없었지만, 지금은 두 대가 있다.  
[ there / be / not / any / computers / in our classroom / but / now / two ] — 주어진 말을 이용하고, 필요하면 단어를 더하거나 형태를 바꾸세요.  
> **정답** There weren't any computers in our classroom, but now there are two. / There were not any computers in our classroom, but now there are two. / There weren't any computers in our classroom, but there are two now. / There were not any computers in our classroom, but there are two now.  
> **해설** computers가 복수라 과거 부정은 There weren't any ~로 쓰고, 지금은 현재형 there are two로 써요.  
> 근거: 1. 과거형 — There was / There were
