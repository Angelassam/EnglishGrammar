## 객관식 (알맞은 말 고르기) (15)

**1.** 우리말과 같은 뜻이 되도록 빈칸에 알맞은 말을 고르세요. / 영어를 배우는 것은 재미있다. / ____ is fun to learn English.  
① It  
② That  
③ This  
④ There  
⑤ To  
> **정답** ① It  
> **해설** to부정사 주어가 길 때는 가주어 It을 앞에 두고 진주어 to learn English를 뒤로 보내요. 이때 It은 '그것'으로 해석하지 않아요.  
> 근거: Part 2. 1. 가주어 It ~ 진주어 to부정사

**2.** 두 문장이 같은 뜻이 되도록 빈칸에 알맞은 말을 고르세요. / To exercise every day is important. / = It is important ____ every day.  
① to exercise  
② exercise  
③ to exercising  
④ exercised  
⑤ exercises  
> **정답** ① to exercise  
> **해설** 가주어 It 뒤의 진주어는 to부정사(to + 동사원형)로 써요.  
> 근거: Part 2. 1. 가주어 It ~ 진주어 to부정사

**3.** 우리말과 같은 뜻이 되도록 빈칸에 알맞은 말을 고르세요. / 그가 이 문제를 푸는 것은 어렵다. / It is difficult ____ to solve this problem.  
① for him  
② of him  
③ for he  
④ of he  
⑤ him  
> **정답** ① for him  
> **해설** difficult는 성격을 평가하는 형용사가 아니라서 의미상 주어를 for + 목적격(for him)으로 써요.  
> 근거: 의미상 주어 — for + 목적격 / of + 목적격

**4.** 우리말과 같은 뜻이 되도록 빈칸에 알맞은 말을 고르세요. / 나를 도와주다니 너는 친절하구나. / It was kind ____ to help me.

④ for your  
⑤ to you  
> **정답** ① of you  
> **해설** kind처럼 사람의 성격을 평가하는 형용사 뒤에는 of + 목적격을 써요.  
> 근거: 의미상 주어 — for + 목적격 / of + 목적격

**5.** 빈칸에 알맞은 말을 고르세요. / It is important ____ us to exercise.

> 근거: 의미상 주어 — for + 목적격 / of + 목적격

**6.** 빈칸에 알맞은 말을 고르세요. / It is kind ____ you to say so.

## 틀린 부분 고쳐 쓰기 (7)

**1.** It is important of us to exercise.  
(우리가 운동하는 것은 중요하다.)  
> **정답** of → for  
> **해설** important는 성격 형용사가 아니라서 의미상 주어를 for + 목적격으로 써요. of → for  
> 근거: 의미상 주어 — for + 목적격 / of + 목적격

**2.** It is kind for you to say so.  
(그렇게 말해 주다니 너는 친절하구나.)  
> **정답** for → of  
> **해설** kind는 사람의 성격을 평가하는 형용사라서 of + 목적격을 써요. for → of  
> 근거: 의미상 주어 — for + 목적격 / of + 목적격

**3.** It is difficult for he to solve this problem.  
(그가 이 문제를 푸는 것은 어렵다.)  
> **정답** he → him  
> **해설** 의미상 주어는 for + 목적격이에요. he → him  
> 근거: 의미상 주어 — for + 목적격 / of + 목적격

**4.** She showed me how use the machine.  
(그녀는 나에게 그 기계를 어떻게 사용하는지 보여 주었다.)  
> **정답** how use → how to use  
> **해설** 의문사 뒤에는 to + 동사원형이 와요. how use → how to use  
> 근거: Part 2. 2. 의문사 + to부정사

**5.** This is fun to learn English.  
(영어를 배우는 것은 재미있다.)  
> **정답** This → It  
> **해설** 뒤로 보낸 to부정사 주어를 대신하는 가주어는 It이에요. This → It  
> 근거: Part 2. 1. 가주어 It ~ 진주어 to부정사

**6.** I don't know what I should to do.  
(나는 무엇을 해야 할지 모르겠다.)  
> **정답** should to do → should do  
> **해설** 의문사 + 주어 + should 뒤에는 to 없이 동사원형이 와요. should to do → should do  
> 근거: 의문사 + 주어 + should + 동사원형으로 바꾸기

**7.** He didn't tell me when starting.  
(그는 나에게 언제 시작할지 말해 주지 않았다.)  
> **정답** starting → to start  
> **해설** '언제 ~할지'는 when to + 동사원형이에요. starting → to start  
> 근거: Part 2. 2. 의문사 + to부정사

## 배열·영작 (7)

**1.** 샌드위치를 만드는 것은 쉽다.  
[ to make / It is / easy / a sandwich ]  
> **정답** It is easy to make a sandwich.  
> **해설** 가주어 It + is + 형용사 + 진주어 to부정사 순서예요.  
> 근거: Part 2. 1. 가주어 It ~ 진주어 to부정사

**2.** 그녀가 중국어를 말하는 것은 어렵다.  
[ for her / It is / difficult / to speak / Chinese ]  
> **정답** It is difficult for her to speak Chinese.  
> **해설** It is + 형용사 + for + 목적격 + to부정사 순서예요.  
> 근거: 의미상 주어 — for + 목적격 / of + 목적격

**3.** 인사를 하다니 그는 예의 바르구나.  
[ of him / It was / polite / to say hello ]  
> **정답** It was polite of him to say hello.  
> **해설** 성격 형용사 polite 뒤에는 of + 목적격 + to부정사 순서예요.  
> 근거: 의미상 주어 — for + 목적격 / of + 목적격

**4.** 나는 언제 멈춰야 할지 모르겠다.  
[ when / I don't know / to stop ]  
> **정답** I don't know when to stop.  
> **해설** 의문사 + to부정사(when to stop)가 know의 목적어로 쓰여요.  
> 근거: Part 2. 2. 의문사 + to부정사

**5.** 아빠는 나에게 의자를 고치는 방법을 보여 주셨다.  
[ how to fix / My dad / showed me / the chair ]  
> **정답** My dad showed me how to fix the chair.  
> **해설** showed me 뒤에 how to fix the chair가 목적어로 와요.  
> 근거: Part 2. 2. 의문사 + to부정사

**6.** 우리는 어느 영화를 볼지 정해야 한다.  
[ which movie / We need / to decide / to watch ]  
> **정답** We need to decide which movie to watch.  
> **해설** decide의 목적어로 which movie to watch(어느 영화를 볼지)가 와요.  
> 근거: Part 2. 2. 의문사 + to부정사

**7.** 내가 언제 와야 하는지 알려 줘.  
[ when / Tell me / come / I should ]  
> **정답** Tell me when I should come.  
> **해설** when to come = when I should come이에요. 의문사 + 주어 + should + 동사원형 순서예요.  
> 근거: 의문사 + 주어 + should + 동사원형으로 바꾸기
