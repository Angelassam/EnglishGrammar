## 객관식 (알맞은 말 고르기) (16)

**1.** 우리말과 같은 뜻이 되도록 빈칸에 알맞은 말을 고르세요. / 서울은 세계에서 가장 큰 도시 중 하나이다. / Seoul is one of the ____ in the world.  
① biggest cities  
② biggest city  
③ bigger cities  
④ big cities  
⑤ most big cities  
> **정답** ① biggest cities  
> **해설** '가장 ~한 것들 중 하나'는 one of the + 최상급 + 복수명사예요. 단수 city는 틀려요.  
> 근거: Part 2 / 1. one of the + 최상급 + 복수명사

**2.** 빈칸에 알맞은 말을 고르세요. / She is one of the best ____ in Korea.  
(그녀는 한국에서 가장 노래를 잘하는 가수 중 한 명이다.)  
① singers  
② singer  
③ singing  
④ sings  
⑤ a singer  
> **정답** ① singers  
> **해설** one of the 뒤에는 복수명사가 와요. → singers  
> 근거: Part 2 / 1. one of the + 최상급 + 복수명사

**3.** 우리말과 같은 뜻이 되도록 빈칸에 알맞은 말을 고르세요. / 이 책이 저 책보다 훨씬 더 재미있다. / This book is ____ more interesting than that one.  
① much  
② very  
③ so  
④ too  
⑤ more  
> **정답** ① much  
> **해설** 비교급을 '훨씬'으로 강조할 때는 much를 써요. very는 비교급을 꾸밀 수 없어요.  
> 근거: Part 2 / 2. 비교급 강조 — much / even / far / a lot / still

**4.** 빈칸에 알맞은 말을 고르세요. / He runs ____ faster than before.  
(그는 예전보다 훨씬 더 빨리 달린다.)  
① even  
② very  
③ so  
④ too  
⑤ much more  
> **정답** ① even  
> **해설** 비교급은 much, even, far 같은 말로 '훨씬'이라고 강조해요. 보기 중에서는 even이 맞고, very는 비교급을 꾸밀 수 없어요. much more faster처럼 겹쳐 쓰지 않아요.  
> 근거: Part 2 / 2. 비교급 강조 — much / even / far / a lot / still

**5.** 다음 중 어법상 옳은 문장을 고르세요.  
① Today is far colder than yesterday.  
② Today is very colder than yesterday.  
③ Today is far cold than yesterday.  
④ Today is far more colder than yesterday.  
⑤ Today is colder far than yesterday.  
> **정답** ① Today is far colder than yesterday.  
> **해설** far + 비교급 + than이 바른 순서예요. very는 비교급을 꾸밀 수 없고, -er과 more를 같이 쓰지 않아요.  
> 근거: Part 2 / 2. 비교급 강조 — much / even / far / a lot / still

**6.** 우리말과 같은 뜻이 되도록 빈칸에 알맞은 말을 고르세요. / 그녀는 오빠만큼 키가 크다. / She is ____ her brother.

② as taller as  
③ taller as

⑤ so tall as

> **해설** '~만큼 …한'은 as + 원급 + as예요. as와 as 사이에는 비교급이 아니라 원급이 와요.  
> 근거: Part 2 / 3. 원급 비교 as + 원급 + as

**7.** 우리말과 같은 뜻이 되도록 빈칸에 알맞은 말을 고르세요. / 이 가방은 저 가방만큼 무겁지 않다. / This bag is not ____ that one.

⑤ as heavy than

> **해설** '~만큼 …하지 않은'은 not as + 원급 + as예요.  
> 근거: Part 2 / 3. not as(so) + 원급 + as

**8.** 우리말과 같은 뜻이 되도록 빈칸에 알맞은 말을 고르세요. / 가능한 한 빨리 와 주세요. / Please come as soon as ____.

② can  
③ possibly  
④ fast  
⑤ quickly

> **해설** '가능한 한 ~하게'는 as + 원급 + as possible이에요.  
> 근거: Part 2 / 3. as + 원급 + as possible

**9.** 우리말과 같은 뜻이 되도록 빈칸에 알맞은 말을 고르세요. / 연습을 많이 할수록, 너는 더 잘하게 된다. / The more you practice, ____ you get.

② better

> 근거: Part 2 / 4. the + 비교급 ~, the + 비교급 …

**10.** 빈칸에 알맞은 말을 고르세요. / ____ we climbed, the colder it became.

> 근거: Part 2 / 4. the + 비교급 ~, the + 비교급 …

**11.** 두 문장의 뜻이 같도록 빈칸에 알맞은 말을 고르세요. / This bag is not as heavy as that one. / = That bag is ____ this one.

> 근거: Part 2 / 3. not as(so) + 원급 + as

**12.** 두 문장의 뜻이 같도록 빈칸에 알맞은 말을 고르세요. / Mt. Everest is the highest mountain in the world. / = Mt. Everest is higher than ____ in the world.

> 근거: Part 2 / 1. 최상급과 같은 뜻의 비교급 표현

> **해설** '어떤 다른 ~도 …보다 더 ~하지 않다'는 No (other) + 명사 + is + 비교급 + than이에요.  
> 근거: Part 2 / 1. 최상급과 같은 뜻의 비교급 표현

**14.** 다음 문장의 뜻으로 알맞은 것을 고르세요. / The higher we climbed, the colder it became.

> **해설** the + 비교급 ~, the + 비교급 … 은 '~하면 할수록 더 …하다'라는 뜻이에요.  
> 근거: Part 2 / 4. the + 비교급 ~, the + 비교급 …

**16.** 우리말과 같은 뜻이 되도록 빈칸에 알맞은 말을 고르세요. / 그는 나보다 훨씬 더 키가 크다. / He is ____ taller than me.

> 근거: Part 2 / 1. 최상급과 같은 뜻의 비교급 표현

**7.** She is one of the best singer in Korea.  
(그녀는 한국에서 가장 노래를 잘하는 가수 중 한 명이다.)  
> **정답** singer → singers  
> **해설** one of the 뒤에는 복수명사가 와요. singer → singers  
> 근거: Part 2 / 1. one of the + 최상급 + 복수명사

## 배열·영작 (7)

**1.** 이 선생님은 우리 학교에서 가장 친절한 선생님 중 한 분이다.  
[ one of / Mr. Lee / is / the kindest teachers / in our school ]  
> **정답** Mr. Lee is one of the kindest teachers in our school.  
> **해설** one of the + 최상급 + 복수명사 순서로 써요.  
> 근거: Part 2 / 1. one of the + 최상급 + 복수명사

**2.** 바다는 호수보다 훨씬 더 깊다.  
[ much / The sea / is / deeper / than the lake ]  
> **정답** The sea is much deeper than the lake.  
> **해설** 강조하는 much는 비교급 바로 앞에 와요.  
> 근거: Part 2 / 2. 비교급 강조 — much / even / far / a lot / still

**3.** 내 강아지는 네 강아지만큼 귀엽다.  
[ as / My puppy / cute / is / as / yours ]  
> **정답** My puppy is as cute as yours.  
> **해설** as + 원급 + as 순서로 써요.  
> 근거: Part 2 / 3. 원급 비교 as + 원급 + as

**4.** 네가 더 많이 미소 지을수록, 너는 더 행복하다고 느낀다.  
[ the happier / The more / you smile / you feel ]  
> **정답** The more you smile, the happier you feel.  
> **해설** The + 비교급 + 주어 + 동사, the + 비교급 + 주어 + 동사 순서예요.  
> 근거: Part 2 / 4. the + 비교급 ~, the + 비교급 …

**5.** 가능한 한 천천히 말해 주세요.  
[ as slowly as / speak / Please / possible ]  
> **정답** Please speak as slowly as possible.  
> **해설** '가능한 한 천천히'는 as slowly as possible이에요.  
> 근거: Part 2 / 3. as + 원급 + as possible

**6.** 이번 여름은 지난여름보다 훨씬 더 덥다.  
[ this summer / far / hot / than / last summer ] — 주어진 말을 이용하고, 필요하면 단어를 더하거나 형태를 바꾸세요.  
> **정답** This summer is far hotter than last summer.  
> **해설** be동사 is를 더하고, hot을 비교급 hotter로 바꿔 far + 비교급 + than으로 써요.  
> 근거: Part 2 / 2. 비교급 강조 — much / even / far / a lot / still

**7.** 이 퍼즐은 저 퍼즐만큼 어렵지 않다.  
[ not / This puzzle / is / as difficult as / that one ]  
> **정답** This puzzle is not as difficult as that one.  
> **해설** '~만큼 …하지 않은'은 not as + 원급 + as 순서예요.  
> 근거: Part 2 / 3. not as(so) + 원급 + as
