# EnglishGrammar — 젤라쌤 중1·중2 문법 문제 생성 앱

중1·중2 영어 문법 정리 문서를 바탕으로 문법 문제를 만들어 주는 앱이에요. (안젤라 영어 교실)

## 앱 여는 방법

1. `app/index.html` 파일 하나만 있으면 돼요. 인터넷이나 서버가 필요 없어요.
2. GitHub에서 받으려면: `app` 폴더 → `index.html` → 오른쪽 위 **Download raw file**(아래 화살표 모양) 버튼을 누르세요.
3. 받은 파일을 컴퓨터나 휴대폰에서 두 번 눌러 열면 앱이 켜져요. (크롬, 사파리, 엣지 모두 돼요.)

## 사용 순서

1. 학년(중1 / 중2)을 고르세요.
2. 단원을 고르세요. 여러 개 골라도 돼요. "교과서로 고르기"에서 출판사와 Lesson을 고르면 그 과에 나오는 단원만 보여요.
3. 문제 유형과 문제 수를 고르세요.
4. **학생용 — 문제 풀기**: 문제를 풀고 "제출하고 채점하기"를 누르면 점수, 정답, 해설이 나와요.
5. **선생님용 — 시험지·답지 만들기**: "시험지 인쇄(문제만)" 또는 "답지 인쇄(정답·해설)" 버튼으로 뽑을 수 있어요. 인쇄 창에서 "배경 그래픽"을 켜면 해설 상자가 더 잘 보여요.

문제는 고를 때마다 무작위로 뽑히고, 보기 순서도 매번 섞여요.

## 폴더 구조

```
app/index.html        ← 완성된 앱 (이 파일만 열면 돼요)
app/data/units.json   ← 단원 목록 (중1 23개, 중2 21개) + 출판사별 Lesson
app/data/bank/*.json  ← 단원별 문제 은행
app/미리보기/*.md      ← 문제 은행을 읽기 쉽게 정리한 확인용 문서
app/src/template.html ← 앱 화면 틀 (문제 은행과 합쳐서 index.html이 돼요)
tools/                ← 만드는 사람용 도구
*.md                  ← 중1·중2 문법 정리 원본 문서 (고치지 않아요)
```

## 문제 은행을 고친 뒤 앱 다시 만들기 (개발용)

```bash
node tools/check_bank.js   # 문제 은행 자동 점검
node tools/preview.js      # 미리보기 문서 다시 만들기
node tools/build.js        # app/index.html 다시 만들기
```
